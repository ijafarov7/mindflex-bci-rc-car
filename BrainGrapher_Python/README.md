# BrainGrapher (Python)

Nachbau des Processing-Sketches aus [`../BrainGrapher/`](../BrainGrapher) in Python mit
PyQt5 und pyqtgraph. Zeigt die rohen EEG-Werte des MindFlex-Headsets live an, ohne dass
Processing installiert sein muss.

```bash
pip install PyQt5 pyqtgraph pyserial
python main_pyqt.py
```

Original: [Processing Brain Grapher](https://github.com/kitschpatrol/Processing-Brain-Grapher)
von Eric Mika, MIT-Lizenz (siehe [`../BrainGrapher/LICENSE.txt`](../BrainGrapher/LICENSE.txt)).
